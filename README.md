# تثبيت Alpine Linux بالكامل

هذا الدليل يشرح التثبيت القياسي لتوزيعة **Alpine Linux** على جهاز فعلي أو آلة افتراضية باستخدام صورة التثبيت الرسمية والبرنامج التفاعلي `setup-alpine`.

> **تحذير مهم:** اختيار القرص ووضع `sys` يمسح القرص المحدد ويعيد تقسيمه وتهيئته. خذ نسخة احتياطية، وتأكد من اختيار القرص الصحيح قبل المتابعة. لا تنفّذ أوامر تهيئة الأقراص على قرص يحتوي بيانات تريد الاحتفاظ بها.

## 1. تنزيل صورة التثبيت والإقلاع منها

1. افتح [صفحة تنزيل Alpine Linux الرسمية](https://alpinelinux.org/downloads/).
2. نزّل صورة **Standard** المناسبة لمعمارية جهازك، مثل `x86_64` لأغلب أجهزة الكمبيوتر الحديثة. اختر صورة مختلفة إذا كانت معمارية جهازك مختلفة.
3. أنشئ USB إقلاعيًا من ملف ISO، أو أرفق ISO بمحاكي/آلة افتراضية، ثم أقلع الجهاز منه.
4. في بيئة التثبيت الحية، سجّل الدخول باسم `root`. عادةً لا توجد كلمة مرور افتراضية في بيئة ISO الحية.

## 2. تشغيل التثبيت التفاعلي

ابدأ معالج الإعداد:

```sh
setup-alpine
```

أجب عن الأسئلة التي تظهر، مثل:

- تخطيط لوحة المفاتيح ومتغيرها.
- اسم الجهاز (hostname).
- واجهة الشبكة وإعدادها عبر DHCP أو يدويًا.
- كلمة مرور `root`.
- المنطقة الزمنية وخادم الوقت.
- مرآة حزم Alpine.
- خادم SSH، إذا كنت تحتاج إلى الدخول عن بُعد.

يمكنك قبول القيم الافتراضية بالضغط على Enter عندما تكون مناسبة.

## 3. اختيار القرص وطريقة التثبيت

عندما يسأل المعالج عن القرص، اختر قرص النظام الصحيح (قد يظهر مثل `/dev/sda` أو `/dev/vda` أو `/dev/nvme0n1`؛ يختلف الاسم حسب الجهاز والآلة الافتراضية).

للتثبيت المعتاد على القرص، اختر وضع:

```text
sys
```

وضع `sys` يثبت نظام Alpine على القرص ويهيئه، وبالتالي **يمحو البيانات الموجودة على القرص الذي اخترته**. اتبع مطالبة التأكيد التي يعرضها المعالج، واختر نظام الملفات المقترح أو المناسب لاحتياجك. لا تختر `data` أو `none` إلا إذا كنت تعرف أن طريقة التثبيت هذه تناسب غرضك.

## 4. إعادة التشغيل

بعد اكتمال المعالج، أزل USB أو افصل ISO من الآلة الافتراضية، ثم أعد التشغيل:

```sh
reboot
```

بعد الإقلاع من القرص، سجّل الدخول باسم `root` باستخدام كلمة المرور التي عيّنتها.

## 5. تحديث النظام وإضافة مستخدم عادي (اختياري)

حدّث فهارس الحزم ثم ثبّت التحديثات:

```sh
apk update
apk upgrade
```

لإضافة مستخدم عادي، استبدل `اسم_المستخدم` بالاسم المطلوب:

```sh
adduser اسم_المستخدم
```

إذا كنت تريد منح المستخدم صلاحية استخدام `sudo`، ثبّت الحزمة وأضف المستخدم إلى مجموعة `wheel`:

```sh
apk add sudo
addgroup اسم_المستخدم wheel
```

تحقق من إعداد `sudo` عبر `visudo` قبل استخدامه، ولا تمنح هذه الصلاحية إلا للمستخدمين الموثوقين.

## ملاحظات

- هذا هو التثبيت القياسي باستخدام `setup-alpine`؛ قد تختلف بعض المطالبات حسب إصدار Alpine والجهاز.
- استخدم صورة التثبيت الرسمية فقط، وراجع [دليل التثبيت الرسمي](https://wiki.alpinelinux.org/wiki/Installation) عند الحاجة إلى تقسيم يدوي أو LVM أو تشفير القرص أو إعدادات خاصة.
- هذا الدليل لا يهيئ القرص بأوامر يدوية؛ دع المعالج يتولى ذلك بعد أن تتحقق من اختيار القرص الصحيح.
